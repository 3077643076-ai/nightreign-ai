# 录制系统周末测试交接

## 下个会话的目标

在家里电脑拉取最新代码后，验证训练场录制系统能否正确输出画面、键鼠、内存状态、reward、Boss 标签和自动分局目录。

## 当前进度

- 已实现键鼠录制、Boss 手动配置、reward 计算、episode meta、自动分局判断、再战控制接口。
- `record.py` 入口已接入新录制链路，默认输出 `data/episode_<时间>_0001`，检测到 win/death 后会写当前局 `meta.json` 并滚到下一局目录。
- 自动点击再战接口已存在，但当前默认关闭，避免第一次真实测试误点。
- 当前验证命令：`PYTHONPATH=. pytest tests -v`，本次结果为 28 passed。
- 真实游戏部分还未校准：Boss HP 归零阈值、死亡判断、再战界面延迟、内存读取 Boss 字段稳定性。

## 待决定的事项

- 是否打开自动再战：先手动确认录制输出正确，再考虑启用 `RetryController(enabled=True)`。
- `boss_hp_pct` 来源是否稳定：如果内存读不到 Boss HP，先只验证玩家 HP/FP/体力和键鼠输入。
- 自动分局阈值是否要放宽：真实游戏里 Boss HP 可能不会严格等于 0，需要周末根据素材调整。
- 是否先做键鼠 BC 数据，还是先继续完善 episode/reward 数据结构。

## 要用到的技能

- `superpowers:systematic-debugging`：真实测试发现录制、内存读取、分局不对时使用。
- `superpowers:verification-before-completion`：每次声称测试通过前必须重新跑命令。
- `superpowers:brainstorming`：如果要改训练路线、自动再战策略或 Boss 机制配置。
- `superpowers:writing-plans`：如果周末测试后要进入下一轮实现。

## 周末最小操作

1. 拉取 GitHub 最新代码。
2. 进入项目目录。
3. 设置 Boss 标签，例如：
   - `set NIGHTREIGN_BOSS_ID=training_boss`
   - `set NIGHTREIGN_BOSS_TYPE=standard`
   - `set NIGHTREIGN_DIFFICULTY=normal`
   - `set NIGHTREIGN_WEAPON=greatsword`
4. 运行 `python record.py`。
5. 进训练场后按 F8 录 30-60 秒。
6. 按 F9 停止。
7. 检查最新 `data/episode_*` 目录：
   - `frames/` 有图片。
   - `inputs.jsonl` 有 `gamepad`、`keyboard`、`mouse`。
   - `rewards.jsonl` 有 `reward`、`events`、`done`。
   - `meta.json` 有 Boss 标签和局结果字段。
   - 如果内存读取成功，`game_state.jsonl` 有 `hp_pct`、`fp_pct`、`stamina_pct`。
